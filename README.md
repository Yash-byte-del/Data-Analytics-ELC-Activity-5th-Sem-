# 🐦 Twitter Sentiment Analysis

## 📌 Project Overview

This project implements a **Twitter Sentiment Analysis system** that trains a machine learning model using a **Hugging Face Twitter dataset** and deploys it as a **real-time Streamlit web application** for live sentiment prediction.

The system allows users to input tweet text and instantly receive sentiment feedback, making it suitable for analyzing public opinions, trends, and social media reactions in real time.

🔗 **Live Streamlit App:**  
👉 https://tweetsentimeter.streamlit.app/

---

## 🎯 Project Objectives

- Build an end-to-end machine learning pipeline for text-based sentiment analysis  
- Apply Natural Language Processing (NLP) techniques on social media data  
- Deploy a trained model as a real-time, user-interactive web application  
- Demonstrate practical usage of sentiment analysis in real-world scenarios  

---

## ✅ Key Features

- Real-time sentiment prediction (Positive / Neutral / Negative)  
- Text preprocessing using NLP techniques  
- TF-IDF–based feature extraction  
- Machine Learning model training and evaluation  
- Interactive Streamlit web interface  
- Low-latency predictions suitable for live usage
